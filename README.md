# Embedded Systems Library
This repository is a collection of personal embedded drivers, tools,
algorithms, graphics utilities, and reusable components developed while
learning and building embedded systems.

It currently contains STM32-focused projects and HAL-based implementations,
but the long-term goal is to gradually evolve into a broader, portable
embedded systems library with cleaner abstractions, multiple platform
backends, tested device drivers, and reusable application-level modules.
